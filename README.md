# 📊 Sales Analytics Dashboard

## 📌 Project Overview

This project is an interactive **Sales Analytics Dashboard** created in Microsoft Excel to analyze sales performance across different **products, regions, and months**.

The dashboard provides a clear and visual overview of key sales metrics, helping users understand sales trends and identify high-performing products and regions.

## 📈 Key Features

- 💰 **Total Amount** – Displays the overall sales amount.
- 🛒 **Total Sales** – Shows the total number of sales transactions.
- 📅 **Sales by Month** – Tracks monthly sales performance and trends.
- 📦 **Sales by Products** – Shows the contribution of each product to total sales.
- 🌍 **Sales by Region** – Compares sales performance across East, North, South, and West regions.
- 🔎 **Interactive Filters** – Filter the dashboard by:
  - Date
  - Region
  - Product
- 📊 **Interactive Charts** – Uses line charts and bar charts for easy comparison and analysis.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers / Timeline
- Excel Formulas
- Data Visualization

## 🎯 Purpose of the Dashboard

The main purpose of this dashboard is to transform raw sales data into an **easy-to-understand visual report**. It helps users monitor sales performance, compare products and regions, analyze monthly trends, and make data-driven business decisions.

## 🔍 Key Insights

The dashboard can be used to identify:

- Which products contribute the most to sales

- Monthly sales trends and fluctuations
- Overall sales volume and revenue
- Changes in performance based on selected filters

## 🚀 Conclusion

This Excel Sales Analytics Dashboard demonstrates how **Pivot Tables, interactive filters, charts, and KPIs** can be combined to create an effective business intelligence dashboard for sales analysis.
